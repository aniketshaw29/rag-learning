# TechNova Inc. — Company Overview

## About TechNova

TechNova Inc. is a mid-size software company founded in **2019** by
**Sarah Chen** and **Marcus Rodriguez**. Headquartered in **Austin, Texas**,
the company specializes in building AI-powered developer tools.

TechNova currently employs **342 people** across three offices:
- **Austin, TX** (HQ) — Engineering, Product, Leadership (180 employees)
- **Toronto, ON** — Engineering, QA, Data Science (112 employees)
- **Berlin, DE** — Sales, Marketing, Customer Success (50 employees)

## Mission Statement

"To accelerate software development by making AI accessible, reliable,
and transparent for every developer."

## Core Products

### NovaCode (Primary Product)
An AI-powered code assistant that integrates into VS Code and JetBrains IDEs.
Key features include:
- Real-time code completion using custom-trained LLMs
- Automated code review with security vulnerability detection
- Natural language to SQL query generation
- Support for 28 programming languages

NovaCode has **120,000+ monthly active users** and generates 68% of
TechNova's revenue.

### NovaTest
An AI testing tool that automatically generates unit and integration tests
from code. Launched in Q2 2024, it currently has **15,000 users**.

### NovaDeploy
A CI/CD platform with intelligent deployment recommendations. Currently
in **beta** with 200 enterprise customers.

## Company Values

1. **Developer First** — Every decision starts with "does this make
   a developer's life easier?"
2. **Transparency** — We publish our AI model cards and training data sources
3. **Quality Over Speed** — We'd rather ship late than ship broken
4. **Continuous Learning** — Every employee gets $5,000/year for education
