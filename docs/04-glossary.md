# Glossary

Key terms used in this project and in RAG generally.

**Chunk**
A small piece of a document. Documents are split into chunks so they fit in
the LLM's context window and so retrieval is more precise.

**Context Window**
The maximum amount of text an LLM can process in a single request. Gemini 2.5
Flash supports up to 1 million tokens.

**Document**
A source file (markdown, PDF, text) that contains knowledge you want the LLM
to access.

**Embedding**
A list of numbers (vector) that represents the meaning of a piece of text.
Generated by an embedding model. Similar meanings produce similar vectors.

**Embedding Model**
A model that converts text into embedding vectors. In this project we use
Gemini's `gemini-embedding-2` model.

**Hallucination**
When an LLM confidently states something that is false or made up. RAG helps
reduce hallucinations by grounding answers in real retrieved text.

**Indexing**
The one-time process of loading, chunking, embedding, and storing documents
in a vector database.

**LLM (Large Language Model)**
A neural network trained on large amounts of text that can generate human-like
responses. Examples: Gemini, GPT, Claude.

**Metadata**
Extra information attached to a chunk, like the source filename, page number,
or section title. Used for filtering and citation.

**Query**
A user's question or search term. In RAG, the query is converted to an
embedding to find relevant chunks.

**RAG (Retrieval-Augmented Generation)**
The technique of retrieving relevant documents and including them in the LLM
prompt to generate grounded answers.

**Retrieval**
The process of finding the most relevant chunks from the vector database for
a given query.

**Similarity Search**
Finding vectors in the database that are closest (most similar) to a query
vector. Usually measured by cosine similarity.

**Token**
A piece of a word. LLMs process text in tokens. Roughly 1 token = 0.75 words
in English.

**Vector**
A list of floating-point numbers representing text meaning. Also called an
"embedding". Vectors with similar meaning are close together in vector space.

**Vector Database**
A specialized database designed to store, index, and search embedding vectors
efficiently. We use ChromaDB.
